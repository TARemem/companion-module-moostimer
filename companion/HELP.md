# MoosTimer

Start MoosTimer 1.0.11 or later and enable its network server. Add the MoosTimer connection in Companion, enter the host IP and port (default **3950**), and choose actions or button presets.

Use only on a trusted local network. The current MoosTimer API does not authenticate requests.

This is a **development build**, not yet approved or listed in the official Companion module library.
